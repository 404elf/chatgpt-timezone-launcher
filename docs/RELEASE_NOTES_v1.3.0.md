# ChatGPT 时区启动器 v1.3.0

修复切换代理后需要重开启动器才能识别新 IP 的问题，并缩短出口检查等待。加入新图标、紧凑界面和窗口拉伸适配，README 也重新整理了。

## 这次更新

- 每次检测重新读取当前 Windows 代理/PAC，使用新连接。同一个启动器内切换代理后，直接点「重新检测」或「启动 ChatGPT」即可。
- 已确认不支持地区时直接提示 IP 错误，不再等第三方时区查询；时区查询并行进行并取消慢请求，网络检测总时限约 7 秒。
- 检测失败时不再把历史 IP 放到当前出口位置。
- 新的聊天时钟图标与卡片界面；手动输入、详情按需展开，小窗支持滚动。
- 保留自动关闭启动器、GitHub 更新下载、地区保护和新版客户端包身份启动修复。

## 下载

下载 `ChatGPT-TimeZone-Launcher-v1.3.0-win-x64.exe` 替换旧程序，原设置保留，无需安装 .NET 或管理员权限。

## 验证

44 项自动化测试通过，包括同一检测器切换两个本地真实代理；当前真实网络三次检测约 1.4 秒，慢请求模拟约 6.7 秒返回失败。时间仅计出口检测，其他网络可能不同；不包含 Windows 启动和 ChatGPT 自身账号登录。具体范围见仓库 `TEST-RESULTS.md`。
