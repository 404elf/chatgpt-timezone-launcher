# ChatGPT 时区启动器 v1.1.2

修复新版 Windows 客户端带时区启动时提示“该进程没有程序包标识符”的问题。启动器现在通过 Windows 包内启动接口保留 ChatGPT 的原包身份，仅向新建 ChatGPT 进程传入 TZ，并验证包身份及初始运行状态。

## 下载与使用

下载 `ChatGPT-TimeZone-Launcher-v1.1.2-win-x64.exe`，无需安装 .NET 或管理员权限。彻底退出正在运行的 ChatGPT，再从启动器选择自动或手动时区并启动；只关闭窗口可能仍驻留后台。

原配置继续使用。恢复默认仍走正常 Windows 应用激活，不修改系统时区、全局 TZ、ChatGPT 文件或用户数据，不强制结束用户进程。

## 更新内容

- 保留当前 ChatGPT 包身份，避免旧版直接运行包内 EXE 的启动错误。
- 检查真实包身份与启动后 3 秒存活情况，明确报告包接口错误、立即退出和超时。
- 默认启动清除调用环境中继承的 TZ。
- 合并并保留已发布 1.1.1 的损坏配置修复、异常日志与最终 EXE 启动检查。

## 验证范围

- 26 项常规测试通过；最终单文件 EXE 的首次启动、损坏配置启动检查通过。
- 在 OpenAI.Codex 26.924.2738.0 的真实独立测试实例中读取页面时区，验证纽约、东京和无覆盖默认时区；发布前对最终 EXE 重验东京和默认时区。
- 用户原有会话保留，系统时区及用户/系统 TZ 保持原值；未测试用户已登录会话的完整退出再登录和全部联网功能。

当前附件适用于 Windows x64，未进行商业代码签名。Windows 包内命令接口属于微软的调试/排障接口，未来客户端或 Windows 更新仍需验证兼容性。详细记录见仓库 `TEST-RESULTS.md`。
