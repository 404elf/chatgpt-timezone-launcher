# ChatGPT 时区启动器 v1.3.1

修复慢网络频繁被判超时的问题：取消 7 秒总限时，单次请求改为最多等待 30 秒。主查询慢时会同时尝试备用接口，原查询继续等待，仍采用第一个有效结果。

- 等待时显示已用时间，可随时点「取消检测」；取消不会弹 IP 错误，也不会启动或关闭 ChatGPT。
- 「检测详情」分别显示获取出口 IP、查询地区和时区的耗时，便于找出等待位置。
- 保留切换代理后的新连接、地区保护和并行时区查询。

下载 `ChatGPT-TimeZone-Launcher-v1.3.1-win-x64.exe` 替换旧程序即可，设置保留。

47 项自动化测试通过，包含 8.5 秒才返回的成功结果、备用查询并行、等待中的界面取消与单次请求防挂起检查。当前网络实测出口 IP 约 1.6 秒、地区与时区约 0.6 秒，具体范围见 `TEST-RESULTS.md`。

出口检查、Windows 启动和 ChatGPT 自身账号登录是不同阶段。放宽等待可以减少检测误失败，不保证客户端账号登录速度；单次请求仍有防永久挂起的限时，多个阶段合计可能超过 30 秒。
