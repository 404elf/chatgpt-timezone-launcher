# ChatGPT 时区启动器 v1.2.0

这次加入出口地区保护、小型更新入口和可选的自动关闭启动器，保留 v1.1.2 对新版 ChatGPT 的启动修复。

## 使用

下载 `ChatGPT-TimeZone-Launcher-v1.2.0-win-x64.exe` 替换旧程序即可，设置会保留，无需安装 .NET 或管理员权限。

- 每次启动前检查 ChatGPT 当前出口 IP。中国大陆、香港、澳门等不支持地区，以及地区未知、检查失败，会提示“IP 错误”并停止启动；手动时区和默认方式也检查。
- 底部“↻ 更新”可检查并下载 GitHub 新版，完成后验证 SHA-256 并打开文件位置；关闭启动器后手动替换即可。
- 可勾选“启动后自动关闭启动器”，默认不勾选，会记住选择。启动失败或取消时不会关闭。

支持地区依据 [OpenAI 清单](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)，核对日期 2026-10-01。判断按国家/地区粒度，GeoIP 可能有误差，无法识别部分地区的局部例外。启动后不持续监控 IP。

36 项自动化测试通过，覆盖地区阻断、未知及失败检测不使用缓存、trace 地区冲突、设置保存、默认启动确认、更新检查及下载校验、窗口布局，并保留包启动和损坏配置回归检查。最终 EXE 首次和损坏配置启动通过；真实新版客户端验证页面时区为 `Asia/Tokyo`，GitHub 下载及校验实测通过。详细范围见仓库 `TEST-RESULTS.md`。
